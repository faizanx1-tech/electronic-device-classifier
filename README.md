
# 🔌 Electronic Devices Image Classifier

## 📌 Project Overview
This project is an AI-based image classification system developed using **Google Teachable Machine**.

The model is trained to recognize and classify seven different types of electronic devices using images.

## 📂 Categories

The model can identify the following seven categories:

1. 📼 Cassettes
2. ⌨️ Keyboard
3. 🔊 Loudspeaker
4. 🎤 Microphone
5. 📺 Remote Control
6. 📱 Smartphone
7. 📺 Television

## 🛠️ Technologies Used
- 🤖 Artificial Intelligence (AI)
- 🧠 Machine Learning
- 🖼️ Image Classification
- 🌐 Google Teachable Machine
- ⚙️ TensorFlow.js

## ⚡ How It Works
1. 📸 The user provides an image.
2. 🔍 The AI model analyzes the image.
3. 🤖 The model identifies the object.
4. ✅ It predicts which of the seven categories the object belongs to.

## 📁 Model Files
- `model.json`
- `metadata.json`
- `weights.bin`

## 🎯 Project Purpose
The purpose of this project is to understand how artificial intelligence and machine learning can be used to recognize different objects through image classification.

## 🧪 Model Training
The model was trained using image samples of seven different categories through Google Teachable Machine.
