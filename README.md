
# Electronic Device Classifier

## Project Overview
This project is an AI-based image classification system developed using Google Teachable Machine.

It is trained to recognize and classify different types of electronic devices from images.

## Technologies Used
- Google Teachable Machine
- Artificial Intelligence (AI)
- Machine Learning
- Image Classification
- TensorFlow.js

## Model Files
- model.json
- metadata.json
- weights.bin

## How It Works
1. The model receives an image.
2. It analyzes the image.
3. It identifies the electronic device.
4. It predicts the category based on its training.

## Model Training
The model was trained using images of different electronic devices through Google Teachable Machine.
1. Cassettes
2. Keyboard
3. Loudspeaker
4. Microphone
5. Remote Control
6. Smartphone
7. Television

## Project Purpose
This project demonstrates the practical use of AI and machine learning for image recognition.
